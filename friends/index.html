申请友链

如果你也有技术博客，欢迎交换友链！

申请方式： 在博客下方留下你的博客信息，我会尽快通过。

基本要求：

  • 拥有独立的个人博客（非纯社交账号）
  • 博客内容以技术分享、学习记录为主
  • 定期更新，保持活跃
  • 提供 博客名称、链接地址、头像图片 URL 和 一句话简介

申请示例：

也可以直接在 GitHub Issues 中提交申请，或在评论区留言。

底部动态壁纸

博客底部那条 B 站同款动态壁纸，使用了以下技术：

项目 说明
Puppeteer 无头浏览器抓取 B 站首页壁纸
GitHub Actions 定时同步壁纸清单
B 站 CDN 图片直接引用 B 站 CDN，零带宽成本

实现思路：抓取 B 站首页多层 PNG 的图层清单（URL + 视差系数），前端实时叠加渲染，鼠标移动时产生视差效果。壁纸更换由 GitHub Actions 每 6 小时自动检测并同步。

详细介绍：让博客壁纸跟着 B 站首页走
